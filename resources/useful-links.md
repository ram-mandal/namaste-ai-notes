# Resources & Further Reading

> Curated external resources that complement the Namaste AI course topics.
> Scoped to what the course actually covers: LLMs, prompt engineering, RAG, AI agents, MCP, and AI engineering.

## 📚 By Course Topic

### AI Fundamentals
- [Attention Is All You Need (Vaswani et al., 2017)](https://arxiv.org/abs/1706.03762) — The transformer paper. Read a simplified walkthrough first.
- [3Blue1Brown: Neural Networks](https://www.youtube.com/playlist?list=PLZHQObOWTDMDh_kMSUAL3mjRzenOuK3VU) — Visual intuition for how models work (optional background)

### Large Language Models
- [The Illustrated Transformer (Jay Alammar)](https://jalammar.github.io/illustrated-transformer/) — Best visual explanation of transformers
- [The Annotated Transformer (Harvard NLP)](https://nlp.seas.harvard.edu/annotated-transformer/) — Transformer code, line by line
- [How LLMs Work (Raschka)](https://magazine.sebastianraschka.com/p/how-llms-work) — Practical, code-backed explanation of LLM internals
- [Why ChatGPT Can Do Math (Joe Hubert Tuhme)](https://www.linkedin.com/pulse/why-chatgpt-can-do-math-its-what-you-think-joe-hubert-tuhme/) — How math ability evolved from pattern prediction to tool-assisted computation

### Prompt Engineering
- [OpenAI Prompt Engineering Guide](https://platform.openai.com/docs/guides/prompt-engineering) — Official techniques and patterns
- [Anthropic Prompt Engineering Overview](https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/overview) — Clear, practical guidance

### RAG (Retrieval Augmented Generation)
- [RAG Overview (LangChain)](https://python.langchain.com/docs/concepts/rag/) — Conceptual walkthrough with code
- [Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks (Lewis et al., 2020)](https://arxiv.org/abs/2005.11401) — The original RAG paper
- [Vector Databases Explained (Pinecone)](https://www.pinecone.io/learn/) — How embeddings and similarity search work

### AI Agents
- [Building Effective Agents (Anthropic)](https://www.anthropic.com/research/building-effective-agents) — Patterns for agent workflows, from simple to complex
- [ReAct: Synergizing Reasoning and Acting in Language Models (Yao et al., 2022)](https://arxiv.org/abs/2210.03629) — The reasoning + acting pattern behind many agents

### MCP (Model Context Protocol)
- [MCP Specification](https://modelcontextprotocol.io/) — Official spec and docs
- [Model Context Protocol (Anthropic announcement)](https://www.anthropic.com/news/model-context-protocol) — Why MCP exists and how it fits together

### AI Engineering
- [A Field Guide to AI Engineering (Anthropic)](https://www.anthropic.com/research/field-guide-to-ai-engineering) — System design for robust AI systems
- [Evaluating LLMs (LangChain)](https://python.langchain.com/docs/concepts/evaluation/) — How to test and measure AI applications

## 💡 Tips for using resources

✅ **DO:**
- Mix sources (videos + text + code)
- Practice immediately after learning
- Bookmark resources you'll return to
- Explain concepts to others

❌ **DON'T:**
- Just collect resources (tutorial trap)
- Jump between too many sources
- Read papers without a simplified explanation first
- Wait for perfect understanding before coding
