## 📄 Papers (Simplified)

**Foundational:**
- [Rosenblatt: The Perceptron (1958)](https://classics.csail.mit.edu/perceptron/) — Birth of neural networks
- [Rumelhart et al.: Backpropagation (1986)](http://www.nature.com/articles/323533a0) — How networks learn

**Modern:**
- [Krizhevsky et al.: AlexNet (2012)](https://papers.nips.cc/paper/4824-imagenet-classification-with-deep-convolutional-neural-networks.pdf) — CNN revolution
- [Vaswani et al.: Attention is All You Need (2017)](https://arxiv.org/abs/1706.03762) — Transformers explained

**Note:** Start with 3Blue1Brown explanations before reading the actual papers.

## 📊 Datasets for Practice

**Easy (Start here):**
- [MNIST](http://yann.lecun.com/exdb/mnist/) — Handwritten digits (70K images)
- [CIFAR-10](https://www.cs.toronto.edu/~kriz/cifar.html) — Small images, 10 categories
- [Iris Flower Dataset](https://archive.ics.uci.edu/ml/datasets/iris) — Classic classification

**Medium:**
- [Fashion MNIST](https://github.com/zalandoresearch/fashion-mnist) — Clothing images
- [IMDB Reviews](https://www.tensorflow.org/datasets/catalog/imdb_reviews) — Text sentiment
- [Boston Housing](https://www.kaggle.com/c/boston-housing) — Regression practice

**Advanced:**
- [ImageNet](http://www.image-net.org/) — Millions of labeled images
- [COCO Dataset](https://cocodataset.org/) — Object detection, segmentation
- [Wikipedia Corpus](https://dumps.wikimedia.org/) — Massive text data

**Curated Datasets:**
- [Kaggle Datasets](https://www.kaggle.com/datasets) — Find any dataset
- [UCI Machine Learning](https://archive.ics.uci.edu/ml/) — Classic datasets
- [Hugging Face Datasets](https://huggingface.co/datasets) — NLP & vision datasets

## 💡 Tips for using resources

✅ **DO:**
- Mix sources (videos + text + code)
- Practice immediately after learning
- Bookmark resources you'll return to
- Explain concepts to others
- Build things with what you learn

❌ **DON'T:**
- Just collect resources (tutorial trap)
- Jump between too many sources
- Read papers without explanations
- Wait for perfect understanding before coding
- Study without applying
