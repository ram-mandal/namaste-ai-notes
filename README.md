# Namaste AI Notes

> Learn Artificial Intelligence concepts from the **Namaste AI course** with clear explanations, real examples, and hands-on projects.

---

## 🎯 What is this?

A **structured learning resource** for the Namaste AI course by Akshay Saini. These notes break down complex AI/ML concepts into simple, digestible lessons with:

- 📝 Clear explanations in plain language
- 💻 Code examples and snippets
- 🎨 Diagrams and visual explanations
- 🚀 Links to hands-on projects
- 📚 Resources for deeper learning

**Target audience:** Anyone wanting to learn AI/ML fundamentals through structured notes and practical projects.

---

## 📖 How to use this repo

### For learners
1. **Start here:** Pick a Season below
2. **Read lessons:** Each lesson explains one core concept
3. **Run code:** Try the examples yourself
4. **Build projects:** Apply what you learned in the projects section
5. **Ask questions:** Check FAQ or open an issue

### File structure
- `season-1/` — All Season 1 lessons and resources
- `projects/` — Links to hands-on projects (separate repos)
- `assets/` — Diagrams, screenshots, visual aids
- `resources/` — External links and reference materials

## 🤝 Contributing

Found an error? Want to add to a lesson? Help improve these notes!

**How to contribute:**
1. Fork the repo
2. Create a branch: `git checkout -b fix/lesson-01-typo`
3. Make changes (follow formatting guide in `.github/copilot-instructions.md`)
4. Commit: `git commit -m "Fix typo in lesson 01"`
5. Push and create a Pull Request

**Contribution guidelines:**
- Keep explanations simple and clear
- Add diagrams or examples when helpful
- Use consistent formatting (see style guide)
- Test code examples before submitting
- Add resources/links at the end of lessons

See `.github/copilot-instructions.md` for detailed formatting rules.
