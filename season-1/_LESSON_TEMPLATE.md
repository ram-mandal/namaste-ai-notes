## 💻 Code example

Here's working code you can run:

```python
# Example: Simple neural network operation
# This code shows [what concept]

import numpy as np

# Create sample data
input_data = np.array([1, 2, 3])  # Your input
weights = np.array([0.5, 0.3, 0.2])  # Random starting weights

# Calculate output
output = np.dot(input_data, weights)
print(f"Input: {input_data}")
print(f"Weights: {weights}")
print(f"Output: {output}")  # Expected: 1.6

# What happened:
# (1 × 0.5) + (2 × 0.3) + (3 × 0.2) = 0.5 + 0.6 + 0.6 = 1.7
```
